# Детектирование медицинских масок (YOLOv8 vs Faster R-CNN)

## 🎯 О проекте
Задача — разработать детектор объектов для контроля ношения медицинских масок. Сравнение двух архитектур: YOLOv8 (одноуровневый) и Faster R-CNN (двухуровневый).

## 📊 Данные
Датасет (853 изображения). Разметка в формате Pascal VOC XML была сконвертирована в формат YOLO. Классы: `with_mask`, `without_mask`, `mask_weared_incorrect`.

## 🛠 Стек
*   **Python**, **PyTorch**, **Ultralytics (YOLOv8)**, **Torchvision (Faster R-CNN)**.
*   **Библиотеки:** OpenCV, Matplotlib, Pandas, Numpy.

## 📈 Результаты (YOLOv8n)
*   **Общий mAP50: 0.821**
*   **with_mask: 0.943** (высокая точность)
*   **without_mask: 0.821**
*   **mask_weared_incorrect: 0.699** (мало примеров в датасете)

## 💡 Выводы
**YOLOv8** показал отличный баланс скорости (~30-60 мс) и качества, что делает его идеальным для систем реального времени. **Faster R-CNN** дает хорошее качество, но тяжелее и медленнее (не подходит для слабого железа).
